"Marketing-Campaign-Performance-Analysis"

Marketing Campaign Performance Analysis using Microsoft Excel and Microsoft PowerBI



Project Overview:

This project analyzes the performance of digital marketing campaigns using Power BI.

The objective is to evaluate campaign effectiveness across different channels, identify conversion trends, and determine which marketing strategies generate the highest return on investment (ROI).


Tools Used

- Excel – Data preparation
- Power BI – Data visualization and dashboard creation
- PowerPoint – Business presentation and storytelling



Dataset Description:

Dataset

The dataset contains marketing campaign performance data including:

- Impressions
- Clicks
- Leads
- Conversions
- Marketing Spend
- Revenue
- Campaign Channel
- Region
- Date




Key Insights

- Email marketing campaigns generated the highest ROI.
- A significant drop occurs between clicks and leads in the conversion funnel.
- Revenue peaks early in campaign periods and stabilizes afterward.


Recommendations

- Increase investment in high-performing channels such as Email Marketing.
- Improve landing page design to reduce the drop between clicks and leads.
- Optimize campaign timing to maintain engagement throughout the campaign period.
